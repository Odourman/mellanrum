Kept as `EVIDENCE/INVALID_PILOTS_AND_TIMEOUTS/natural_bank1_RC1_wrong_PC_INVALID.log`; fixed in controller script then full native RC1 match PASS. **Harness issue, NOT RC1/LAB product fail.**
3. **Initial roomload parser error:** script initially gathered both `F2D8` and `F2F0` next-PC outputs instead of the specific next PC for each instruction, falsely classifying a parse failure. Fixed parser to select correct instruction context and reran on unchanged original Gopher logs. Raw error text kept under invalid pilot folder. **Parser failure, not ROM timing regression.**
4. **FRI A/A2/B/B2 strict raw PCM:** same ROM RC1 independently captures 694,036 different int16 values; same ROM LAB 752,110. These *are real sample differences*, but under same-ROM unstable oracle, an A/B difference cannot be attributed specifically to LAB. A real LAB-specific *internal TIA sound timing* difference **is** independently demonstrated in the 2142 natural branch: six register writes exactly three colorclocks earlier. That difference is documented, not discarded or mislabeled as audible glitch.
5. **No new confirmed LAB-specific 263-line/timer/stack/bank/room-advance product failure** was reproduced in natural targeted cases. Forced RAM diagnostic scenarios are not proof of player reachability. Global all-path INCONCLUSIVE is a scope limit, not a failure witness.
