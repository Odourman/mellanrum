# Reproducera den sista riktade oberoende MELLANRUM-verifieringen

**Inga produktändringar.** Exakt RC1 respektive LAB är read-only binärer i `ROMS/`, källsnapshot i `SOURCE_SNAPSHOT/`. Kontrollera först med `sha256sum`, se `PROVENANCE/IDENTITIES.json`. Hashar gäller **råa** ROM-bytes, inte filnamn. Använd originalarkiven från Drive för full tidigare bevisning och exakt pinned Gopher2600 executable; detta ZIP innehåller *nya* bevis med referens till originalens SHA, och distribuerar inte emulatorns ELF.

Efter unzip: `unzip -t MELLANRUM_HEALTH_LAB_FINAL_TARGETED_VERIFICATION_EVIDENCE_2026-11-25.zip`; `sha256sum -c SHA256SUMS.txt` från rot. Ange dina egna pathar vid reproduktion, eftersom scriptsen bevarar verifierarens **exakta historiska absoluta path-värden** under `/mnt/data/LAB_FINAL_TARGETED`. Alla originalkommandon i `EVIDENCE/**/commands.txt`, `EVIDENCE/*/*.script` och `SCRIPTS/`; inga hemliga tokens finns i paketet. Alla testskript använder oförändrade cartridge-bytes och original pinned native emulator.

## Tidsbas och status

Gopher `TRACE STRICT` gives **true CPU/TIA/RIOT bus accesses** with `FR`, `SL`, `CL`; this pinned version reports CL relative to 68 colorclocks after HBlank origin, so `colorclock = CL +68`. An `ONSTEP CPU,TIA` instruction-start TIA state is **not** an STA actual bus write. WSYNC sometimes appears post-stall; calculate its issue deadline from verified instruction cycles and actual boundary, not blindly from the post-stall location. Each ROM has different relocated bank3 PC (e.g. RC1 caller F706, LAB F708; renderer F78E vs F790). Preserve forced-state-vs-natural labels in the ledgers. One `TV FRAME` query is a **sample**, not a unique frame execution. CPU clock observations and controller frame steps are different counts.

All artifacts were checked for expected ROM SHA before each test series. Exits 0 and parser assertions are in `EVIDENCE/`/`work_logs`. Machine `ANALYSIS/TEST_MATRIX.csv` distinguishes new test, prior verification, prior Pachinko, NOT_RUN, negative control and invalid pilot.
